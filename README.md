# CLI Calculator

A simple command-line calculator application written in Python that provides basic arithmetic operations and unit conversions.

## Features

### Basic Calculator
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Error handling for invalid inputs
- Continuous operation until user chooses to exit

### Unit Converter
Supports conversion between:
- Celsius and Fahrenheit
- Kilometers and Miles
- Kilograms and Pounds

## Usage

1. Run the calculator:
```python
python calculator.py
